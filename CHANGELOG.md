# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow
[Semantic Versioning](https://semver.org/).

## [1.0.0] — 2026-10-14

First public release.

### Added
- Eight deterministic diagram types: architecture (incl. DFMEA and electronic
  schematic profiles), workflow, sequence, dataflow, lifecycle, fishbone,
  mindmap, roster.
- Interactive single-file viewer: trace animation, route probe, upstream /
  downstream reachability, semantic passport, grouped node index, themes and
  presets, print-safe export.
- File-as-database editing: in-browser drag/label editing, save-back to the
  same file, embedded history with rollback, AI re-editing contract.
- Presentation deck builder with page-enter effects and an encrypted
  single-file share bundler.
- Full deterministic test gates: schema validation, golden renders,
  real-browser checks (1900+ assertions).
